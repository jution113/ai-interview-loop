# ADR-0003: 답변 종료 후 일괄 STT 처리

- **상태:** 수락됨(Accepted)
- **영역:** Backend
- **작성일:** 2026-11-24
- **작성자 / 참여자:** 주성천 / ChatGPT

## 1. 배경 및 맥락 (Context)

- 음성 답변을 텍스트로 변환해 동적 꼬리질문과 면접 종료 후 평가에 활용한다. MVP의 질문·준비·답변·분석 흐름에서는 답변 도중 AI가 개입할 필요가 없다.

## 2. 결정 (Decision)

- 답변 타이머가 만료되거나 사용자가 답변 완료를 누르면 음성 수집을 끝내고 수집된 음성을 한 번에 STT로 변환한다. 답변 텍스트는 필요 시 꼬리질문을 생성하는 데 사용하고 면접 종료 후 평가에 활용한다.

## 3. 결과 및 영향 (Consequences)

### 긍정적 영향

- 실시간 연결과 중간 변환 결과를 관리할 필요가 줄어든다.

### 부정적 영향 및 트레이드오프

- 답변이 끝난 뒤 STT와 질문 생성에 따른 대기 시간이 발생한다.

### 후속 조치

- **우선순위:** 중간. 녹음 전달과 STT 연동 전에 검토한다.
- 타이머 만료와 답변 완료 클릭이 겹쳐도 최초 STT 요청이 한 번만 시작되도록 한다. 실패 후 재시도·건너뛰기 전이, 임시 음성 사본의 보관 위치와 성공·건너뛰기·세션 종료 시 제거 시점을 정리한다.
- 브라우저 녹음 형식과 STT 입력 형식의 호환성, 빈 답변의 처리 기준을 검토한다.
- 구현 후 STT 실패 시 재시도와 임시 음성 정리를 확인한다. 답변 종료부터 STT 완료까지와 다음 질문 음성 재생까지의 지연을 각각 측정한다. 허용 지연 기준을 검토하고, 면접 흐름에 지장이 있다면 스트리밍을 재검토한다.

#### 향후 논의 · STT 및 TTS 공급자

- 실제 음성 연동 작업에 착수할 때 후보 비교와 기술 검증을 진행한다. STT는 로드맵 4.1에서 검토한다. 질문 TTS는 [MVP 기획서 v0.16](../mvp-spec.md)에 따라 MVP에서 제외하며, 아래 TTS 후보와 검증 항목은 향후 재검토용으로 보존한다. 후보와 측정 계획은 현재 미확정 상태다.
- STT 후보는 whisper.cpp, Faster Whisper, 외부 STT API다. TTS 후보는 Web Speech API의 로컬 한국어 음성, MeloTTS, 외부 TTS API다.
- 한국어와 한영 혼합 기술 용어의 인식·발음 품질, 지연, CPU와 메모리 사용량, 비용, 데이터 외부 전송과 보관 정책, Spring Boot 통합 복잡도, 설치·실행 편의성을 비교한다. 원본 답변 음성, 전사 텍스트, 합성용 질문 텍스트의 전송 여부는 각각 확인한다. 브라우저 TTS를 채택할 경우 서버 TTS 전제와 재생 완료 이벤트 흐름을 별도로 검토한다.
- STT는 동일한 가상 녹음과 정답 전사로 비교한다. 한국어 일반 답변과 한영 혼합 답변, 60·90·120초 구간, 낮은 음량·생활 소음·무음을 포함한다. 한국어 문자 오류율, 기술 용어 누락·치환, 숫자·부정어 오류, 무음의 허위 전사를 확인한다.
- 답변 수집 종료부터 전사 텍스트 확보까지의 시간을 첫 실행과 모델 로드 후로 나눠 측정한다. 포맷 변환, 모델 로딩, 로컬 추론 또는 외부 업로드·응답을 구분하고, 반복 측정의 중앙값과 p95를 기록한다. 모델 버전·정밀도·언어 설정·VAD·스레드 수 등 비교 조건을 남긴다.
- Apple M4·16GB 개발 환경에서 STT 단독과 로컬 LLM 가드레일이 메모리에 로드된 상태를 비교한다. 실제 흐름에서 실행이 겹치는 경우 동시 실행도 검증한다. CPU·메모리 사용량, 메모리 압력과 스왑을 기록하며 최종 후보는 답변 종료부터 다음 질문 텍스트 표시까지도 측정한다.
- TTS는 동일한 한영 혼합 질문을 사용해 한국어 자연스러움, 기술 용어 전달력, 첫 재생까지의 시간을 비교한다. 외부 API 검증은 사용자 승인과 설정이 있을 때 가상 자료로 수행한다.

### 검증 결과

- 미검증

## 4. 검토한 대안 (Alternatives Considered)

| 대안 | 장점 | 단점 | 채택 여부 및 판단 근거 |
|---|---|---|---|
| 실시간 스트리밍 STT | 답변 중 변환을 진행해 종료 후 대기 시간을 줄일 가능성이 있다. | 실시간 연결과 중간 결과 처리의 복잡도가 추가된다. | 미채택. 답변 도중 AI가 개입할 필요가 없어 일괄 처리를 채택했다. |
