# ADR-0002: 모노레포 구조 채택

- **상태:** 수락됨(Accepted)
- **영역:** Common
- **작성일:** 2026-11-24
- **작성자 / 참여자:** 주성천 / ChatGPT

## 1. 배경 및 맥락 (Context)

- Spring Initializr로 백엔드를 초기화했다. AI Interview Loop는 프런트엔드와 백엔드가 모두 필요한 1인 개발 프로젝트로, 소스 코드와 기획서, 기술적 의사결정 문서를 함께 관리한다.

## 2. 결정 (Decision)

- 프런트엔드와 백엔드를 하나의 Git 저장소에서 관리한다. 백엔드는 `backend/`, 프런트엔드는 `frontend/`, 기획서와 ADR 등은 `docs/`에 둔다. 프런트엔드 디렉터리는 구현 단계에서 추가한다.

## 3. 결과 및 영향 (Consequences)

### 긍정적 영향

- 프런트엔드와 백엔드에 걸친 변경과 관련 문서를 함께 검토할 수 있다.

### 부정적 영향 및 트레이드오프

- 향후 독립적인 빌드나 릴리스가 필요하면 추가 구성이 필요할 수 있다.

### 후속 조치

- **우선순위:** 낮음. 프런트엔드가 추가되는 시점에 보강한다.
- 프런트엔드와 백엔드의 빌드 및 실행 방법을 README에 기록한다.
- `backend/`, `frontend/`, `docs/`의 책임과 각 빌드·실행 절차의 문서 위치를 명시한다. 프런트엔드 빌드 결과가 백엔드 실행에 필요한지는 [ADR-0001](0001-local-web-application.md)의 서빙 방식 검토 결과에 연결한다.
- 구현 후 새 체크아웃에서 README 절차만으로 프런트엔드와 백엔드를 빌드하고 실행할 수 있는지 확인한다.

### 검증 결과

- 미검증
