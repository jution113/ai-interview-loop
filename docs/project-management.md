# 프로젝트 관리

## GitHub Projects와 Issue 관리

- GitHub Projects에서 Issue별 작업 상태를 관리한다.
- 기존 Issue를 프로젝트 카드로 활용하며 중복 등록하지 않는다.

## 상태 갱신과 완료 기준

- 착수 조건과 계획 승인이 갖춰진 Issue는 `Ready`로 표시한다.
- 작업에 착수하면 `In Progress`로 바꾼다.
- 개발자 검증이나 PR 리뷰를 요청하면 `In Review`로 바꾼다.
- 필수 검증을 마치고 사용자 승인 후 `dev`에 병합되면 `Done`으로 바꾼다.
- 로드맵, Issue, PR 및 GitHub Projects의 상태를 일관되게 유지한다.

## 상태 갱신 실패와 권한 부족

- 프로젝트 상태 변경에 실패하거나 권한이 없는 경우 사용자에게 보고한다.
